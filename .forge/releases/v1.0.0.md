# Forge v1.0.0 — Stable Release

> **"AI coding agents are temporary. Project context should not be."**

Forge v1.0.0 is the initial stable release of Forge — a portable, agent-agnostic project context layer for AI coding agents.

## Highlights

- **Filesystem-based & Agent-Agnostic**: Works across Freebuff, OpenCode, Antigravity, and other compatible coding agents. Zero new runtimes, daemons, databases, dashboards, or proprietary memory formats.
- **Specification-First Development**: Built around `FORGE_SPEC.md` with stable requirement IDs (`FR-xxx`, `NFR-xxx`, `AC-xxx`), living architecture decisions (`ADR-*.md`), and executable verification.
- **Handoff Without Conversation**: Proven cold-start continuation where fresh agents resume interrupted sessions directly from persisted context (`KICKOFF.md`, `state.md`, `tasks.md`) and git history without prior conversational context.
- **Dedicated Clean Template**: The installable product artifact lives cleanly on the `forge-template` branch (tagged `v1.0.0`), free of development artifacts and development state.

## Installation

From the root of your existing repository:

```bash
# Add Forge as a dedicated remote
git remote add forge https://github.com/SSHRIHARI006/FORGE

# Fetch the stable v1.0.0 template branch
git fetch forge forge-template

# Adopt the template files into your working tree
git checkout forge/forge-template -- .
```

Then commit and instruct your coding agent:
> *"Read `.forge/INIT.md` and follow it exactly to initialize this project."*
